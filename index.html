    Capítulo 3

    Preparar los datos

    Antes de modelar hubo que dejar la información en un formato que los algoritmos pudieran usar.

    Quitar constantes

    Si todos los pacientes tienen el mismo valor en una columna, esta no distingue a nadie. Se eliminaron para evitar ruido y sobreajuste.

    Codificar en 0 y 1

    Las variables cualitativas pasaron a números: 1 si el dato está presente, 0 si no.

    Fijar cortes con ROC

    Para cada valor de laboratorio se buscó el límite que maximiza el índice de Youden y se marcó si el paciente lo cruza.
